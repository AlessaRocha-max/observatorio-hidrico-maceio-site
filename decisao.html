Apoio à decisão

Classificar em grupo

Método CPP-ROC-SORT: cada pessoa dá notas, o método junta as opiniões e coloca cada opção numa classe, dizendo também quando ela fica no limite entre duas classes.

Como usar

  1. Classes — as caixas em que as opções vão cair, da menor para a maior.
  2. Critérios — o que é avaliado, do mais importante para o menos importante. A ordem define o peso de cada um.
  3. Notas — cada decisor dá uma nota de 1 a 5 para cada opção em cada critério, e diz onde fica a fronteira entre as classes.
  4. Resultado — aparece na hora, embaixo. Mude qualquer número e veja o que acontece.

Sobre o exemplo

Não é mapa de risco nem alerta. As fronteiras entre as classes e a incerteza são valores de exemplo, que o grupo ainda vai definir.

2. Notas de cada decisor

Notas de 1 (pouco) a 5 (muito). As linhas em cinza são as fronteiras entre as classes.

3. Resultado

Em ordem, da maior classe para a menor.

δ vai de −1 a +1. Positivo: a opção passa da fronteira. Negativo: fica abaixo. Perto de 0: está no limite.

Como a conta é feita

1. Peso de cada critério (ROC)

2. Mesma régua para tudo

Todas as notas e fronteiras vão para uma régua de 0 a 1 (a menor nota digitada vira 0, a maior vira 1).

3. Chance de passar da fronteira

Como nenhuma nota é exata, cada uma é tratada como incerta (a "incerteza" de cada critério, na régua de 0 a 1). Daí sai a probabilidade de a opção passar de cada fronteira, critério por critério, somada com os pesos.

4. Opinião do grupo

Faz-se a média entre os decisores (todos com o mesmo peso). As fronteiras usadas são a média das fronteiras de cada um. O índice δ = 2 × probabilidade − 1.

5. Classe

A opção cai na classe acima da última fronteira que ela passa (δ ≥ 0). Se algum δ fica entre −ε e +ε, o resultado mostra as duas classes daquela fronteira.
